# Ed25519 Signing/Verification in Python (PyNaCl)

## RFC 8032 Status
RFC 8032 (EdDSA) เผยแพร่ January 2017, status: Proposed Standard — reference หลักสำหรับ Ed25519 [34][35]
ครอบคลุม Ed25519, Ed25519ctx, Ed25519ph, Ed448, Ed448ph — test vectors ใน Section 7 [33][35]

## PyNaCl API
`nacl.signing.SigningKey` (private) และ `VerifyKey` (public) — sign/verify บน 32-byte seed [26][31]

```python
from nacl.signing import SigningKey
sk = SigningKey.generate()
signed = sk.sign(b"message")
vk = sk.verify_key
vk.verify(signed)  # raises BadSignatureError if invalid
